AR GAME
=======

An augmented reality sorting game. A physical board with four ArUco markers
at the corners is detected via webcam; the region between the markers is
warped to fill the window. Players use their finger to drag animal sprites
into their matching colored zones. Finger tracking is done via skin color
detection in HSV space.

FILES
=====

AR_game.py
----------
Main script. Handles ArUco marker detection, perspective warping, finger
tracking, sprite logic, game state management, and rendering via pyglet.
The game has three states: instructions, playing, and results.

aruco_sample.py
---------------
Sample code provided by the course (ITT) demonstrating ArUco marker
detection with OpenCV. Used as reference for detector setup and marker
drawing in AR_game.py.

opencv_pyglet.py
----------------
Sample code provided by the course (ITT) showing how to capture webcam
frames with OpenCV and display them in a pyglet window using the cv2glet()
conversion function. Used as the base structure for AR_game.py.

assets/
-------
- pig.png, hippo.png     Animal sprites (Kenney Animal Pack, CC0)
- Fredoka-VariableFont_wdth,wght.ttf    UI font (Google Fonts, OFL)

NOTES
=====
- The board can temporarily leave the frame during gameplay; the last known
  position is kept for up to 45 frames (MISS_THRESHOLD) before the game
  pauses and prompts the user to reposition the board.
- Skin detection HSV range was calibrated by manual testing and may need
  adjustment depending on lighting conditions and skin tone.
- The finger reference point is offset 10px downward from the topmost
  contour point to better match the actual fingertip position.
